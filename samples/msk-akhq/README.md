# Amazon MSK with AKHQ UI

Terraform sample of [Amazon MSK](https://aws.amazon.com/fr/msk/) with [AKHQ UI](https://akhq.io).

---

## Features

- **Managed Kafka (MSK)**: Industrial-grade Kafka cluster with IAM authentication.
- **AKHQ UI**: Web interface for managing and monitoring Kafka topics, consumers, and clusters.
- **ECS Integration**: AKHQ is deployed on ECS Fargate for high availability.
- **Auto-Scaling**: ECS service auto-scaling enabled for the AKHQ UI.
- **Secure Access**: Protected by Application Load Balancer (ALB) and explicit security groups.

## Quick Start

### 1. Prepare Docker Image
Copy AKHQ docker image to ECR private repository:

```bash
# Get ECR login
aws ecr get-login-password --region eu-west-3 | docker login --username AWS --password-stdin **********.dkr.ecr.eu-west-3.amazonaws.com

# Create repository
aws ecr create-repository --repository-name kafka/akhq

# Copy image (using crane)
crane cp tchiotludo/akhq:0.28.0 **********.dkr.ecr.eu-west-3.amazonaws.com/kafka/akhq:0.28.0
```

### 2. Deploy Infrastructure
Set `TF_VAR_acm_certificate_arn` (ACM certificate of the HTTPS listener) in the root `.env`, see `.env.example`.
The AKHQ admin password is generated; read it with `terraform -chdir=infra output -raw akhq_admin_password`.

```bash
# Initialize (needs TF_VAR_state_bucket in the root .env) and apply, from the repository root
task msk-akhq:init
task msk-akhq:apply
```

### 3. Access AKHQ
The UI will be available at the ALB hostname provided in the outputs.

## Tests

```bash
# terraform test on a throwaway Floci container (fake credentials, no AWS account), from the repository root
task msk-akhq:test
```

The test applies the stack on the emulator (`infra/tests/floci.tftest.hcl`); the gaps of the emulator are mocked in the
test file with the reason as a comment. CI runs it on every pull request (`build-msk-akhq`).

## Task commands

| Command | Description |
|---|---|
| `task msk-akhq:init` | Initialize Terraform with the shared S3 state bucket |
| `task msk-akhq:plan` | Plan the changes |
| `task msk-akhq:apply` | Apply the changes |
| `task msk-akhq:destroy` | Destroy the resources |
| `task msk-akhq:test` | `terraform test` on Floci |
| `task msk-akhq:docs` | Regenerate the Terraform documentation |

Terraform reference (inputs, outputs, resources): [`infra/TFDOCS.md`](infra/TFDOCS.md), generated by pre-commit.

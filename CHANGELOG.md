# CHANGELOG.md - MCO Run Log

## [2026-07-14] - Daily Log - Security leak remediation, AWS provider v6 / terraform-aws-modules majors migration, missing CI/CD stood up, IaC hardening (KMS logs, VPC Flow Logs, TLS policy, least-privilege IAM), Graviton cost optimization

- **Security (P1)**: removed a real AWS account ID and ACM certificate ARN hardcoded in `msk-akhq/infra/alb.tf` (now a required `acm_certificate_arn` variable); replaced a hardcoded demo password hash in the AKHQ config with a Terraform-generated `random_password`; removed a hardcoded RDS endpoint and disabled TLS verification from the (currently unwired) `sample-rds-iam-auth` Lambda; cleaned a stray personal name and a broken local-machine image path out of two READMEs; stopped tracking `.DS_Store`.
- **Bug fixes**: fixed a remote-state key mismatch (`states/aws-lab/vpc` vs the actual `states/aws-lab/base` key) that broke `terraform_remote_state` lookups for every sample depending on `base`; fixed missing/mismatched Terraform outputs and a missing ECS cluster resource that made `ecs-task`'s `task run` non-functional; fixed an ALB security group only opening port 8080 while the listener is on 443.
- **Obsolescence**: upgraded the AWS provider (`~> 5.70` &rarr; `~> 6.0`, verified against the official v6 upgrade guide resource-by-resource) and `terraform-aws-modules` majors (`vpc` 5.13.0&rarr;6.6.1, `ecs` 5.11.4&rarr;7.5.0, `msk-kafka-cluster` 2.5.0&rarr;3.3.0, `rds-aurora` 9.11.0&rarr;10.3.0, `security-group` ~>5.0&rarr;6.0.0) across all 5 samples, migrating every renamed/reshaped input (`cluster_name`&rarr;`name`, `security_group_rules`&rarr;`security_group_ingress/egress_rules`, `monitoring_interval`&rarr;`cluster_monitoring_interval`, etc.); bumped MSK to the AWS-recommended Kafka `3.9.x`, Aurora PostgreSQL to `16.13`, pinned `nginx`/`amazonlinux` image tags; bumped pre-commit hook revisions and added the `check-json`/`detect-private-key` hooks already mandated by this repo's own `AGENTS.md`.
- **CI/CD**: added the GitHub Actions pipeline (`.github/workflows/ci.yml`) that did not exist; fixed `.gitlab-ci.yml`, which referenced a `vpc/.gitlab-ci.yml` path removed by the earlier `samples/` refactor. Both pipelines now run pre-commit, `terraform validate`/`fmt` per sample, KICS and Trivy, without requiring cloud credentials in CI.
- **Hardening**: enabled VPC Flow Logs, added KMS encryption on every CloudWatch Logs group, upgraded the ALB TLS policy and `drop_invalid_header_fields`, scoped several IAM wildcards to specific resource ARNs, added `validation` blocks to every input variable, and replaced unexplained `kics-scan ignore` markers with written justifications or real fixes.
- **Cost**: moved `ecs-service` and `ecs-task` Fargate tasks to Graviton (ARM64), ~20% cheaper at equivalent performance.
- **Docs**: regenerated all `TFDOCS.md`, removed stale embedded copies from sample READMEs, fixed broken root `README.md` links.

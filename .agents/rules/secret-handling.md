# Secret Handling Rule

Strictly FORBIDDEN to scan, hardcode, or push ANY sensitive information that could compromise the cloud account security or identity.

This includes, but is not limited to:
 - access key
 - project id
 - secret key
 - token
 - password
 - private key
 - public key
 - ssh key
 - nom prenom, email, DCP...

Always use and reference variables or secure secret managers instead.
